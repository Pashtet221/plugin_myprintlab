# Print Proof Workflow 1.3.0

## Логика

Каждая строка заказа, содержащая файл, имеет отдельный статус проверки:

- `pending` — проверяется;
- `passed` — проверка пройдена;
- `failed` — проверка не пройдена, клиент должен загрузить новый файл;
- `awaiting_confirmation` — файл исправлен на стороне типографии, клиент должен скачать и подтвердить;
- `approved` — исправленный файл подтверждён клиентом.

Пока хотя бы одна строка имеет `pending`, `failed` или `awaiting_confirmation`, заказ находится в `file-review` («На проверке файла»).

Когда все строки получили `passed` или `approved`, заказ автоматически переводится в `awaiting-payment` («Ожидает оплаты»). Клиент получает ссылку WooCommerce на оплату на странице заказа и по email.

## Исходящий webhook при создании заказа

В массиве `items` теперь передается `item_id`. Он обязателен для обратного ответа по конкретному файлу.

## Callback автоматической проверки

Endpoint:

`POST /wp-json/ppw/v1/file-result`

Заголовок:

`X-PPW-Secret: <секрет из WooCommerce → Print Workflow>`

### 1. Проверка пройдена

```json
{
  "order_id": 123,
  "item_id": 456,
  "result": "passed",
  "message": "Файл соответствует требованиям"
}
```

### 2. Проверка провалена

```json
{
  "order_id": 123,
  "item_id": 456,
  "result": "failed",
  "message": "Недостаточное разрешение. Загрузите новый файл."
}
```

На странице заказа появится форма повторной загрузки. Новый файл автоматически получает статус `pending` и снова отправляется в настроенный исходящий webhook с событием `print_file_reuploaded`.

### 3. Файл исправлен и требует подтверждения

```json
{
  "order_id": 123,
  "item_id": 456,
  "result": "modified",
  "proof_url": "https://example.com/files/fixed.pdf",
  "message": "Слои объединены, размер приведён к формату. Проверьте макет."
}
```

Клиент увидит ссылку на исправленный файл и кнопку подтверждения. После подтверждения строка получает `approved`.

## Ручное управление

В админке заказа для каждой загруженной позиции можно вручную выбрать результат проверки, указать комментарий клиенту и URL исправленного файла. После сохранения плагин автоматически пересчитывает общий статус заказа.
